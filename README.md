# Лабораторная работа

Вариант 16. Виртуальный питомец "Тамагочи"

Описание программы

Представляет собой консольную игру "Тамагочи", в которой пользователь ухаживает за виртуальным питомцем.

Основные характеристики:
- голод
- настроение
- энергия
- возраст

Пользователь может корить питомца, играть с ним, укладывать его спать, проверять его состояние и менять имя. Также предусмотрены случайные события.

Список команд

feed — покормить питомца.

play — поиграть с питомцем.

sleep — уложить питомца спать.

status — посмотреть характеристики и состояние питомца.

rename — изменить имя питомца.

help — вывести список доступных команд.

exit — завершить игру.
